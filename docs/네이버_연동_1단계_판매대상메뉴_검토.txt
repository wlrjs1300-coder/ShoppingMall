네이버 스마트스토어 연동 1단계 — 판매 대상 메뉴 검토
작성일: 2026-08-09

1. 점검 기준

- 실제 실행 DB(server/tteokjip.db)의 상품 31개를 기준으로 확인함
- 현재 판매 중(active)인지 확인함
- 바로 구매(direct) 상품인지, 상담 전용(consultation) 상품인지 구분함
- 상세 이미지 등록 여부를 함께 확인함
- 가격과 원산지는 추후 일괄 최신화하기로 한 상태이므로, 이번 단계에서는 판매 대상 후보만 정함
- 상품 데이터는 이번 점검에서 수정하지 않음


2. 1차 판매 후보 — 18개

현재 판매 중이고 바로 구매 상품이며, 상세 이미지가 등록되어 있는 메뉴입니다.

01. 깨송편
02. 가래떡
03. 흰절편
04. 쑥절편
05. 콩설기
06. 찹쌀떡
07. 약식
08. 꿀떡
09. 과일경단
10. 꿀설기
11. 쑥설기
12. 흑미호박샌드
13. 인절미
14. 쑥인절미
15. 카스테라 인절미
16. 흑임자 인절미
17. 찰시루떡
18. 완두배기 찰떡

판단: 위 18개를 네이버 스마트스토어의 1차 일반 판매 대상으로 삼는 것이 가장 안전합니다.


3. 별도 결정이 필요한 판매 후보 — 1개

- 모듬찰떡

현재 상태:
- 판매 중(active)
- 바로 구매(direct)
- 팩 가격 4,000원
- 팩 중량 230g
- 상세 이미지 4개 등록
- 팩과 말 단위로 모두 판매하는 상품
- DB의 반말·한말 가격은 아직 비어 있음

주의 사항:
- 현재 프로젝트의 네이버 상품 연결 로직은 옵션이 설정된 네이버 상품을 지원하지 않음
- 따라서 팩/반말/한말을 한 상품의 선택 옵션으로 연결하면 현재 연동 검증에서 거부됨

권장안:
- 1차 오픈에서는 모듬찰떡을 ‘팩 상품’으로만 등록·연결
- 반말/한말은 가격 확정과 옵션 연동 개발 이후 추가

대안:
- 모듬찰떡 전체를 1차 오픈에서 보류
- 팩, 반말, 한말을 네이버에서 각각 독립 상품으로 운영

현재 권장 판단: 팩 상품만 1차 판매 대상에 포함


4. 현재 보류할 바로 구매 상품 — 7개

다음 메뉴는 이번 1차 판매 대상에서 제외하는 것이 적절합니다.

- 쑥개떡: 판매 중이지만 상세 이미지가 비어 있음
- 수박설기: 판매 중지 상태이며 상세 이미지가 비어 있음
- 잡과병 모듬설기: 판매 중지 상태이며 상세 이미지가 비어 있음
- 콩찰떡: 판매 중지 상태이며 상세 이미지가 비어 있음
- 호박찰떡: 판매 중지 상태이며 상세 이미지가 비어 있음
- 견과류찰떡: 판매 중지 상태이며 상세 이미지가 비어 있음
- 무지개떡: 판매 중지 상태이며 상세 이미지가 비어 있음

참고:
- 사용자가 앞서 쑥개떡, 수박설기, 잡과병 모듬설기, 콩찰떡, 호박찰떡, 견과류찰떡의 상세 페이지 작업은 우선 진행하지 않기로 결정함
- 무지개떡은 관리자에서 별도로 추가된 실행 DB 상품이며 초기 상품 코드에는 없음


5. 상담 전용으로 유지할 메뉴 — 5개

- 백일떡
- 수수팥떡
- 답례떡
- 단체주문
- 송편 예약

판단:
- 현재 프로젝트의 네이버 연결 검증은 상담 전용 상품을 연결 대상으로 허용하지 않음
- 가격이 정해진 일반 판매 상품이 아니므로 1차 상품 연동 대상에서 제외함
- 스마트스토어에는 직접 판매 상품으로 억지로 등록하지 않고, 현재 홈페이지의 상담 흐름을 유지하는 것이 안전함


6. 1단계 잠정 결론

- 일반 판매 대상: 18개
- 조건부 판매 대상: 모듬찰떡 1개(우선 팩 상품만 권장)
- 보류 대상: 7개
- 상담 전용 유지: 5개
- 합계: 31개

권장 1차 네이버 판매 범위는 일반 판매 18개와 모듬찰떡 팩 상품 1개를 합친 총 19개입니다.


7. 1단계 확정 전에 사용자가 결정할 사항

[ ] 위 일반 판매 후보 18개를 모두 1차 판매 대상으로 확정할지
[ ] 모듬찰떡은 우선 팩 상품만 판매할지, 아니면 전체 보류할지
[ ] 판매 중지된 6개와 쑥개떡을 이번 오픈에서 제외할지
[ ] 상담 전용 5개는 네이버 연동에서 제외하고 홈페이지 상담으로만 유지할지


8. 다음 단계로 넘길 항목

판매 대상 확정 후 다음 단계에서 아래 정보를 최신화해야 합니다.

- 팩 중량 및 판매 단위
- 반말·한말 판매 여부와 가격
- 원재료명과 원산지
- 네이버용 상품명
- 대표 이미지
- 배송 가능 범위와 배송비
- 재고 및 품절 처리 방식
