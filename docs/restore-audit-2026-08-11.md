# 최종 UI·상품 상세 데이터 복구 점검

작성일: 2026-08-11

작업 브랜치: `fix/restore-final-ui-and-product-details`

배포 상태: **미배포 — 사용자 확인 전 배포 금지**

## 복원 완료

- PWA 메인 카테고리의 `ALL`, `01`, `02` 번호를 숨기고 메뉴 이름만 표시하는 기존 최종 스타일 적용 확인
- PWA 메인 배너의 높이·텍스트 영역·하단 간격과 터치 스와이프 코드 보존 확인
- 변경된 PWA CSS/JS가 이전 서비스워커 캐시에 가려지지 않도록 자산 버전과 cache name 갱신
- 관리자 주문 상세의 개인정보 접근·수정 영역을 카드, 드롭다운, 입력 필드, 버튼 단위로 재구성
- 모바일 관리자 주문 상세에서는 개인정보 입력 영역이 한 열로 배치되도록 보완
- 상품 상세 이미지가 비어 있는 기존 기본 상품만 채우는 schema migration 29 추가
- 관리자가 이미 설정한 상세 이미지와 관리자 추가 상품은 migration이 덮어쓰지 않도록 보호
- 로컬 DB에서 상세 이미지 보유 기본 상품 23개 확인
- 모듬찰떡을 제외하고 배포 DB에서 누락됐던 22개 상품의 복구 대상 확인
- README 자동 테스트 수치 최신화

- 주문·결제·생산·재고·개인정보 보호·Naver Commerce 연동 코드

## 정확한 원본 그대로 복원하지 못한 부분

### 관리자 개인정보 영역의 마지막 픽셀 단위 시안

마지막으로 사용자가 확인했던 완성 화면이 Git commit이나 별도 이미지로 남아 있지 않습니다. 기능 구조와 기존 관리자 디자인 체계를 기준으로 재구성했으므로, 당시 화면과 픽셀 단위로 동일하다고 보장할 수 없습니다. 로컬 화면을 사용자에게 보여 주고 간격·크기·색상 확인이 필요합니다.

### 과거 대화 중 커밋되지 않은 미세 UI 조정

마이페이지 버튼 위치, 모달 간격 등 여러 차례 수치가 변경된 항목은 최종 승인 시점의 별도 비교 이미지가 모두 남아 있지 않습니다. 현재 코드에는 관련 PWA 스타일이 존재하고 자동 테스트도 통과하지만, 기억에 의존해 임의 변경하지 않았습니다. 사용자가 현재 화면에서 누락을 지목하면 해당 항목만 복구해야 합니다.

### production 실제 반영

사용자 요청에 따라 commit, push, PR, Render 배포 및 production DB 변경은 수행하지 않았습니다. 따라서 공개 사이트에는 아직 기존 UI와 누락된 상세 이미지 상태가 유지됩니다. 사용자 확인 후 배포해야 migration 29가 production DB의 빈 상세 이미지 필드를 채웁니다.
